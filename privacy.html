Kebijakan privasi

RumahSoftwareOri Backup merupakan aplikasi internal yang dioperasikan oleh pengelola RumahSoftwareOri untuk backup sistemnya sendiri.

Data dan tujuan akses

Dengan izin pemilik akun, aplikasi menggunakan token OAuth Google untuk mengunggah, membaca, memeriksa, dan menghapus berkas backup yang digunakan melalui aplikasi ini dengan cakupan drive.file. Metadata nama, ukuran, waktu, dan checksum berkas dipakai untuk verifikasi dan retensi. Aplikasi tidak meminta akses menyeluruh ke Drive, Gmail, kontak, atau kalender.

Penyimpanan dan perlindungan

Arsip sistem dapat mencakup data akun reseller, riwayat transaksi, serta konfigurasi pemulihan. Arsip dienkripsi sebelum dikirim ke Drive pemilik akun. Kunci privat untuk membuka arsip disimpan terpisah dari VPS. Token koneksi disimpan secara privat untuk menjalankan backup terjadwal.

Penggunaan dan pengungkapan

Data digunakan untuk pencadangan, verifikasi, retensi, dan pemulihan sistem. Arsip dikirim ke Google Drive melalui API Google dan tidak dibagikan secara publik oleh aplikasi. Data Google tidak digunakan untuk iklan, dijual, atau digunakan untuk melatih model AI umum. Penggunaan data Google mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use yang berlaku.

Masa simpan dan pencabutan

Target retensi backup database adalah 7 hari dan arsip lengkap 30 hari di folder backup. Kegagalan koneksi dapat menunda pembersihan. Berkas lama dipindahkan ke Trash Google Drive; pemilik akun dapat mengelola Trash melalui Google Drive. Izin aplikasi dapat dicabut melalui pengaturan koneksi akun Google. Pencabutan menghentikan akses berikutnya, tetapi tidak otomatis menghapus arsip yang sudah ada. Pemilik dapat menghapus arsip tersebut langsung di Drive.

Kontak

Pertanyaan atau permintaan terkait aplikasi dapat disampaikan ke pengelola RumahSoftwareOri di Telegram.
